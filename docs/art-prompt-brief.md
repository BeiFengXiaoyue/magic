# 美术提示词撰写任务书

> 给**撰写提示词的 AI** 的唯一入口。写完必须过机器检查，不靠人读。

## 唯一依据

1. [04 契约](contracts/04-art-assets.md) —— §4 文件格式、§5 书写规则（§5.1 结构 / §5.2 tag 映射 / §5.4 实测效力 / **§5.5 硬规则**）
2. [assets/prompts/_style.md](../assets/prompts/_style.md) —— 风格前缀、通用负向、类别修饰段的**唯一出处**

**不要修改 `_style.md`**。它是全库乘数，改了要全库重拼；需要改就先改契约、走一次提交。

## 交活标准

```powershell
& $py tools\artgen.py lint
```

必须 **`0 个错误，0 个警告`**。现有 12 份素材已全部清零，新素材按同一标准来：

- 警告「内容描述含否定式」→ 把 `no characters` 改写成 `an unoccupied room` 之类；
- 警告「canvas 不在档位」→ 改成 1024×576 / 1024×768 / 768×768；
- 警告「写了透明背景」→ 改成「纯灰底（出图后抠底）」。

## 五条硬要求

1. **`canvas`**：室内场景 `1024x576`、森林地图 `1024x768`、其余（物件/角色/图标/地形/特效）`768x768`。必须是 **8 的倍数**。
2. **正向三段按序拼接**，一字不改地使用 `_style.md` 里的风格前缀与类别修饰段——lint 会逐字比对。
3. **内容描述里不写否定式**（`no` / `without` / `never` / `not`）。实测无效。改肯定句：写 `flat front-facing cutout`，不写 `no side faces`。
4. **物件必须带背景子句**（已在 prop 类别段里），效果是背景变成纯中灰、可一键抠底。**不要写 `transparent background`**——模型出不了 alpha，透明靠后处理。
5. **负向照抄**：通用负向 + 类别负向。它的作用是"人眼核对清单"，**不保证生效**，别指望它拦住什么。

## 内容描述怎么写（§5.3）

先**构图**（画面里有什么、在哪、几个），再**明暗**（光从哪来、哪片是暗部），最后**焦点**（玩家该看哪里）。
数量词写明确（`a single crucible`、`three shelves`），不用"许多/丰富"这类模糊词。

## 不要做的事

- 不要把交互物件烤进场景图（坩埚、柜台、床由独立 `prop` 叠加）
- 不要写 `status: generated` 或填 `seed`——那是出图阶段的事
- 不要新增未在 04 契约 §7 清单登记的 `art_id`（先登记再建文件）
