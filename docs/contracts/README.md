# 规范契约（Contracts）

> 契约与设计文档冲突时：**以设计文档为准**，并回来修正契约。

## 状态

- **草案**：可讨论，字段可能变。
- **评审**：已冻结讨论，等待一方（策划 / 实现）确认。
- **已定**：实现的硬依据。改动必须走一次提交 + 变更记录。
