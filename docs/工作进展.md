### 2.2 共享内核（`src/core/`）

- 内容载入与 14 条校验：`content_database.gd`、`content_validator.gd`。
- 平衡求解：`reaction_solver.gd`（贪心多反应、K 排序、表序 tie-break）+ `equilibrium_solver.gd`（单反应二分）。
- 确定性随机：`deterministic_rng.gd`（6 条流、快照/恢复）。
- 时间：`game_clock.gd`（20 小时一天、绝对日 `today()`）。
- 状态类型：`craft_result.gd`、`inventory.gd`、`product_instance.gd`、`wallet.gd`。
- 感知/投影：`perception.gd`、`projection.gd`。

### 2.3 领域层（`src/domain/`）

- 过程：`process_engine.gd`、`craft_process.gd`、`craft_session.gd`、`gather_process.gd`、`wild_spawner.gd`。
- 经济：`economy.gd`（覆盖率、成本、定价）。
- 角色：`character_state.gd`（HP / 理智；M2 只接采集扣理智）。

### 2.4 编排层（`src/app/`）

- `craft_use_case.gd`：O1 炼一炉；产物入库存。
- `gather_use_case.gd`：O2 采集；固定点再生、野生点消费、扣理智、推时间。

### 2.5 引擎层（`src/engine/`）

- `main.gd`：组装根；场景、HUD、面板、时间驱动与事件接线。
- `world/`：`world_view.gd`、`player.gd`、`scene_layout.gd`、`interactable_node.gd`。
  - `scene_layout.gd`：室内 1280×720 可行走矩形、出生点、门与家具阻挡；森林几何改由 `forest.json` 提供。
  - `player.gd`：WASD 移动、按场景矩形限制位置、Camera2D 跟随、AABB 障碍滑动。
  - `world_view.gd`：森林底图（缺图用纯色）、JSON 景物、固定/野生节点、节点再生灰化；不绘制道路或常规网格。
- `ui/`：`game_hud.gd`、`crucible_panel.gd`、`material_shelf.gd`、`observation_panel.gd`、`shop_panel.gd`、`bubble_view.gd`、`ui_theme.gd`。

### 2.6 场景边界与相机（本轮追加）

- 室内（工坊/小店）：1280×720；可行走矩形四周留 48px 墙，玩家位置限制在房间内，**不能从门以外离开**。
- 室内坩埚、床、柜台是实体阻挡，不可穿越；门嵌在墙上（工坊右墙两扇、小店左墙一扇），靠近按 E。
- 森林：3200×2400；四周留 64px 边界；Camera2D 以玩家为中心跟随，地图边缘处自动夹住。
- HUD 与面板放在独立 `CanvasLayer`，不随相机移动。
- 森林地形/道路完全由地图底图 `art_scene_forest` 承载；代码不画路、不画常规网格。
- `forest.json` 定义 3200×2400 尺寸、出生点/入口、32 个定点树木/岩石、5 个刷新区域与野生规则。

- 按 B 打开布点模式：显示刷新区域轮廓、habitat 标签与坐标网格（默认关闭）。

## 4. M2 人工验收路径

1. 开局在炼药工坊；右侧下方门去 **晨暮森林**（E）。
2. 靠近采集点按 E：
   - **野生清露草**：4 个点，每点 2 份，位置每天随机刷新。
   - **野生风蚀砂**：2 个点，每点 1 份。
   - **固定苔衣 ×2、石英砂 ×1**：位置在 `nodes.json`，采集后 3 天再生。
   - 按 **B** 可以看到刷新区域与坐标网格；森林地形/道路由以后的地图底图承载，代码不画路。
   - 每次 10 游戏分钟、理智 −2；空手率 20%；野生点采集后消失，第二天重刷。
3. 回工坊，靠近坩埚按 E：投 **清露草 ×3 + 苔衣 ×1**，微火，点火；按 T 加速，完成后取出。
4. 右侧上方门去 **小店**，靠近柜台按 E：
   - 温润汤剂覆盖率约 **0.58**，报价 **12 金**，可卖。
5. 再炼 **清露草 ×3 + 风蚀砂 ×1**（乱投，无配方）：
   - 柜台覆盖率约 **0.41**，按钮为「卖不掉」。

> 清露草野生点一轮合计 8 份，足够温润汤剂（3）与杂配酊（3），不必等再生。

## 5. 关键规则备忘

- 时间：45 现实秒 = 1 游戏小时；T1 炼制 60 游戏分钟 = 45 现实秒。
- 采集：10 游戏分钟/次，理智 −2（成功与空手相同），基础空手率 20%，柴刀修正 ×1.0。
- 再生：T1 3 天；`GameClock.today()` 为绝对日。
- 定价：`P = clamp(P₀ × 季节系数 × 覆盖率 × 弹性项, 成本×1.1, P₀×1.3)`；覆盖率 < 0.5 直接返回 0。
- 基准价：温润汤剂 12、退热酊 10、乱投兜底 8。
- 成品：每瓶不可堆叠，覆盖率和价格由 `CraftResult` 现算，不存派生值。
- 确定性：固定种子 9173271；`craft` / `gather` / `device` 等流各自消费，可快照恢复。

## 6. 已知限制与风险

- **无存档**：重启丢进度；存档契约字段已留，SaveSystem 计划 M4 前补。
- **无战斗、信件、手记、灵性、天气、种植、订单、机械路线**：均为后续里程碑。
- **森林地图底图尚未生成**：当前是纯色地面 + JSON 占位树木/岩石；道路将随 `art_scene_forest` 图片出现，代码不再绘制道路。
- **定点景物/资源坐标是占位值**：地图图片生成后，改 `forest.json` 的 scenery/spawn_zones 与 `nodes.json` 即可重新布点。
- **野生刷新状态只在内存**：同一天重复进出稳定，跨天重刷；退出游戏会重置，M4 前补持久化。
- **树木/岩石按 `collision_radius` 阻挡**；设为 0 的景物可穿过。
- **开局库存为空**：M2 起材料由采集提供，这是刻意设计。
- **价格地板可能吞掉覆盖率差异**：温润汤剂成本 11、地板价 12.1、P₀ 12，当前报价 12；若要让覆盖率更明显地影响价格，调 `base_price` 或材料价即可，不改代码。
- **GUI 点击全流程尚未自动化**：headless 测试覆盖 O2/O3 逻辑，主场景冒烟覆盖组装；柜台实际点击建议按 §4 人工走一遍。
- **契约状态仍标草案**：02 已按实现回填到 v0.4；00/01 补了 items/nodes 与 `scene_`；04 美术仍草案。
- **测试负例会打印 `push_error`**：这是内容校验负例的预期输出，不代表测试失败。
- `.uid` 文件随 Godot 4.7 生成，建议随代码提交；`.zcode/` 已加入 `.gitignore`。
