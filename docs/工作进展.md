## 4. M2 人工验收路径

1. 开局在炼药工坊；底墙右侧门（x=651）去 **晨暮森林**（E）。
2. 靠近采集点按 E：
   - **野生清露草**：4 个点，每点 2 份，位置每天随机刷新。
   - **野生风蚀砂**：2 个点，每点 1 份。
   - **固定苔衣 ×2、石英砂 ×1**：位置在 `nodes.json`，采集后 3 天再生。
   - 按 **B** 可以看到刷新区域与坐标网格；森林地形/道路由以后的地图底图承载，代码不画路。
   - 每次 10 游戏分钟、理智 −2；空手率 20%；野生点采集后消失，第二天重刷。
3. 回工坊，靠近坩埚按 E：投 **清露草 ×3 + 苔衣 ×1**，微火，点火；按 T 加速，完成后取出。
4. 底墙左侧门（x=280）去 **小店**，靠近柜台按 E：
   - 温润汤剂覆盖率约 **0.58**，报价 **12 金**，可卖。
5. 再炼 **清露草 ×3 + 风蚀砂 ×1**（乱投，无配方）：
   - 柜台覆盖率约 **0.41**，按钮为「卖不掉」。

> 清露草野生点一轮合计 8 份，足够温润汤剂（3）与杂配酊（3），不必等再生。

## 5. 关键规则备忘

- 时间：45 现实秒 = 1 游戏小时；T1 炼制 60 游戏分钟 = 45 现实秒。
- 采集：10 游戏分钟/次，理智 −2（成功与空手相同），基础空手率 20%，柴刀修正 ×1.0。
- 再生：T1 3 天；`GameClock.today()` 为绝对日。
- 定价：`P = clamp(P₀ × 季节系数 × 覆盖率 × 弹性项, 成本×1.1, P₀×1.3)`；覆盖率 < 0.5 直接返回 0。
- 基准价：温润汤剂 12、退热酊 10、乱投兜底 8。
- 成品：每瓶不可堆叠，覆盖率和价格由 `CraftResult` 现算，不存派生值。
- 确定性：固定种子 9173271；`craft` / `gather` / `device` 等流各自消费，可快照恢复。

## 6. 已知限制与风险

- **无存档**：重启丢进度；存档契约字段已留，SaveSystem 计划 M4 前补。
- **M3 不做解密**：火烤/蘸水/折叠/字谜/焦页/修复按 05 §12 后置；M3 只做普通信件。
- **信件/手记 UI 无自动化测试**：headless 覆盖 D3/O4 与引导链，面板靠实机截图检查。
- **无战斗、信件、手记、灵性、天气、种植、订单、机械路线**：均为后续里程碑。
- **主角只有左右两套行走图**：上下移动复用左右贴图，纯垂直时沿用上一次朝向；背面图不生成（t2i 对正面有强先验）。
- **森林底图已有，但树木/岩石仍烘焙在底图里**：有背景图时跳过 JSON 景物的绘制与碰撞，树干无法单独遮挡玩家；要拆树需重生成无树底图 + `art_prop_tree_set`。
- **定点景物/资源坐标是第一版**：已按森林图对齐，后续调整只需改 `forest.json` 与 `nodes.json`，不改代码。
- **野生刷新状态只在内存**：同一天重复进出稳定，跨天重刷；退出游戏会重置，M4 前补持久化。
- **开局库存为空**：M2 起材料由采集提供，这是刻意设计。
- **价格地板可能吞掉覆盖率差异**：温润汤剂成本 11、地板价 12.1、P₀ 12，当前报价 12；若要让覆盖率更明显地影响价格，调 `base_price` 或材料价即可，不改代码。
